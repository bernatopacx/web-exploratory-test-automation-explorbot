# Chatbot Project Reference

This file is project context, not a universal rule.

The `Plan widget testlerini` project conversation is a required historical source for widget-by-widget testing. It covers finance, weather, directions, music, happy and negative paths, offline/throttling/recovery, responsive and dark-theme checks, Figma comparison, browser execution, screenshots, and reporting. Re-check current Jira requirements before reusing any case.

The project history also includes DeepSearch, language/pronunciation, release-retest, visual, and backend/infrastructure checks. Keep their entitlement and evidence assumptions separate.

An inspected `hubxco/be-chatbot-wl` checkout contained infrastructure migration material and example services, not the full chatbot business backend in the inspected scope. Do not infer chat completion, DeepSearch, regenerate/cancel, upload, export, credits, quota, subscription, or business endpoint behavior from that repository alone.

Past evidence exposed a failure mode where screenshots all showed only the authenticated landing page and videos were blank. Reject that as proof for an interaction case. Capture the action and resulting state.
